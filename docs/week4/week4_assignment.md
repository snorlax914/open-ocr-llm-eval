# 4주차 과제

## 주제 : 카테고리 추천 모델 재검증 및 RAG 기반 마크다운 Chunking 전략 수립

---

## 1. 모델 효율성 및 지시 이행력 재검증

a. Qwen3:4B-Instruct 모델을 사용하여 4B 모델이 8B보다 느린 현상 및 Reasoning 잔존 문제를 해결하기.

b. VRAM 점유율과 시간 등 다시 벤치마킹 해보기.

c. 벤치마킹 결과를 고려했을 때, 가장 적합한 모델은 무엇인지 제안하기.

## 2. 영문 프롬프트 기반 적응형 카테고리 명명 고도화

a. 프롬프트 본문은 영문으로만 작성하고, 결과값(기존 카테고리명 및 새 카테고리 제안)은 반드시 한국어로 출력되도록 지시 강화하기.

b. 새 카테고리를 지을 때 기타, 확인서 와 같이 모호한 이름이 나오지 않도록 명명 규칙을 강화하기.

c. (선택) 프롬프트 길이 압축하기.

## 3. 마크다운 Chunking 전략 탐색

a. OCR로 추출된 마크다운 데이터를 LLM이 가장 잘 이해할 수 있는 단위로 쪼개는 실험을 진행하기. (langchain-text-splitters 사용)

b. langchain-text-splitters 의 아래 클래스 사용해보고 각각 장단점 비교하고 평가하기.

  - i. RecursiveCharacterTextSplitter
  - ii. MarkdownHeaderTextSplitter
  - iii. TokenTextSplitter
  - iv. SemanticChunker

## 4. Chunking 시 Overlap 전략 탐색

a. 청크 간의 정보 단절을 막기 위해 앞뒤 내용을 일부 겹치게 하는 Overlap 비율이 답변 품질에 미치는 영향 탐색하기.

b. 마크다운 표 데이터가 Chunking 과정에서 잘렸을 때, Overlap이 데이터 복원에 얼마나 도움이 되는지 탐색하기.
